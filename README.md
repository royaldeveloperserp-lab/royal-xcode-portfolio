# Royal xCode Technologies Portfolio Starter

A responsive, single-page static portfolio website built with HTML and CSS.

## Deploy with Cloudflare Pages
1. Upload `index.html` to the root of a GitHub repository named `royal-xcode-portfolio`.
2. Open Cloudflare Dashboard → Workers & Pages → Create application → Pages → Connect to Git.
3. Authorize GitHub and select `royal-xcode-portfolio`.
4. Set production branch to `main`.
5. Since this is plain static HTML, use build command `exit 0` and build output directory `/` (or follow the current Cloudflare dashboard's static HTML instructions if it asks for a directory).
6. Deploy and open the generated `*.pages.dev` address.
